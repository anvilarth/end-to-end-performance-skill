Авторы сравнивают bitsandbytes и GPTQ в Transformers. По их выводам GPTQ быстрее при генерации, bnb быстрее при LoRA-дообучении, а потеря качества мала. Сверка шла с несколькими записями библиотеки, исчерпывающая новизна не утверждается.

## Приём 1: Автор замерил Llama-2-13b на A100-80GB с промптом 512 при bs 1 и 16.

**Наблюдение автора:** Автор: в prefill при bs=1 GPTQ/exllama даёт 33.711 мс против 36.958 мс у fp16. При bs=16: GPTQ 95.41 мс, fp16 69.94 мс, bnb 113.98 мс.

**Результат автора:** Автор: bnb и GPTQ эквивалентны, GPTQ немного быстрее при большом батче. Наш вывод по таблице: при bs=16 оба медленнее fp16. Дельта к R3f3037a20c228735acb63dc3-1 условная: там генерация 512/512 при bs=1, здесь prefill и 13b. Смена знака видна только внутри этого источника.

**Условия и ограничения:** Только prefill, A100, 4-bit, два значения батча.

**Наш проверочный эксперимент:** Наш эксперимент: развёртка bs 1–32 для fp16 и W4 отдельно по prefill и decode.

**Раздел источника:** Inference speed (forward pass only)

## Приём 2: Автор сравнил LoRA-дообучение GPTQ и bnb на Llama-2-7b, A100.

**Наблюдение автора:** Автор: для дообучения GPTQ пришлось отключить exllama.

**Результат автора:** Автор: bnb быстрее, величина есть только на графике (unknown). Дельта к R3f…-1 (наша): ядро, быстрое в инференсе, может быть недоступно в обучении.

**Условия и ограничения:** PEFT/LoRA, auto-gptq на момент поста.

**Наш проверочный эксперимент:** Наш эксперимент: время шага fwd+bwd с фиксацией фактически включённого ядра.

**Раздел источника:** Adapter fine-tuning (forward + backward)

## Приём 3: Автор сравнил модели на Open-LLM leaderboard.

**Наблюдение автора:** Автор: средний балл 7b — 54.32 / 53.4 (bnb) / 53.23 (GPTQ). Для 13b — 58.66 / 56.9 / 57.56; ревизия actorder_True даёт 58.03.

**Результат автора:** Автор: большие модели деградируют меньше. Наш расчёт противоречит этому: потеря bnb растёт с 0.92 до 1.76, у GPTQ около 1.1 на обоих размерах. Причина разницы между ревизиями GPTQ unknown: настройки дефолтной ревизии не указаны. Роль act_order остаётся нашей гипотезой.

**Условия и ограничения:** Одно семейство Llama-2, два размера, средние leaderboard без оценки разброса.

**Наш проверочный эксперимент:** Наш эксперимент: целевая метрика по размерам с act_order и без, на одном чекпойнте, с повторами.

**Раздел источника:** Performance degradation
